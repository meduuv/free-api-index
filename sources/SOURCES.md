## Important

A source directory can become stale. Provider documentation is authoritative for endpoint behavior, authentication, limits, pricing and terms.

Jentic Public APIs is CC0-1.0 and focuses on structured OpenAPI and Arazzo knowledge for agents. Its specifications remain an external source rather than being copied wholesale into this repository.

The Ultimate API List advertises more than 50,000 records, while the imported README category data currently represented in this repository contains 16,654 records after deduplication against the local catalog. Verify upstream terms before redistributing source-specific data.
