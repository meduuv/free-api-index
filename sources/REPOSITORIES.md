## Notable scale sources

- [kawsarlog/Ultimate-API-List](https://github.com/kawsarlog/Ultimate-API-List) — advertises 50,371 API records across 17 categories. Its dataset is kept as an external source because its licensing/terms need to be verified before bulk redistribution.
- [exa-studio/ApiVault](https://github.com/exa-studio/ApiVault) — large categorized API catalog.
- [gunjanjaswal/Awesome-Public-Free-Apis](https://github.com/gunjanjaswal/Awesome-Public-Free-Apis) — self-updating free REST API collection.
- [public-api-lists/public-api-lists](https://github.com/public-api-lists/public-api-lists) — curated free API directory with JSON data.
- [Spinov001-art/free-apis-list](https://github.com/Spinov001-art/free-apis-list) — no-key/free API collection.

The main dataset only incorporates records that can be redistributed with reasonable source attribution; external catalogs remain linked for discovery rather than being copied wholesale.
